# Roule ou pas

Appli web pour iPhone : savoir si on peut faire un trajet à moto selon la météo, et avec quel équipement.

- Itinéraires (trajet maison ↔ boulot par défaut, aller et retour sur deux plages horaires)
- Adresses réelles en France (Géoplateforme IGN) et villes du monde (Open-Meteo)
- Durées calculées par la route (OSRM)
- Météo heure par heure à chaque point du trajet (Open-Meteo)

Installation : ouvrir l'adresse GitHub Pages dans Safari, puis Partager → Sur l'écran d'accueil.
